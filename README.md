# Boston Transit to Scale

How long is an MBTA Green Line **Type 10 "Supercar"**? This page draws it to scale next to trains, buses, planes and Boston landmarks.

## Two modes

- **How long is a Type 10?** (`#compare`, default): step through 29 comparisons, one at a time, against a 113 ft 8 in Type 10. Use ← → keys or the Prev/Next buttons. Trains have a car-count stepper.
- **Transit sandbox** (`#sandbox`): stack any number of tracks on one shared ruler. Pick presets, swap vehicles, change car counts, reorder, and switch between feet and meters. Your setup is saved in your browser.

## What's in it

Green Line Types 7, 8, 9 and 10, Mattapan PCC, Red Line 1700/1800/1900, Orange Line 1400, Blue Line 700, Silver Line and 40 ft buses, Commuter Rail (HSP46 + bilevels), NYC R211, Chicago 7000-series, NextGen Acela, plus cars, trucks, jets, courts, a blue whale, the Statue of Liberty, Bunker Hill Monument and the Green Monster.

Lengths are to scale; shapes are simplified. Items marked ≈ are typical sizes. Vehicle lengths come from Wikipedia's MBTA rolling-stock articles. Not affiliated with the MBTA.

## Run it

It's plain HTML, CSS and JS with no build step. Open `index.html`, or publish with GitHub Pages (Settings → Pages → deploy from the `main` branch, root folder).

```
index.html   page structure and both modes
style.css    styles, light and dark themes
app.js       vehicle catalog, drawing code, interactions
```
